# Partner patches

The original notebook copies two modified files from Google Drive:

- `training_loop.py`
- `misc.py`

To reproduce that environment, obtain the exact files from the teammate and
place them here as:

```text
patches/training_loop.py
patches/misc.py
```

Then run:

```bash
bash scripts/apply_partner_patches.sh
```

Do not recreate the files from notebook output. Version the exact source files
and document what was changed.
